Astro 7, prerendered to static pages, with Tailwind 4 reading one file of design tokens. Type is Geist and Geist Mono, served from this site, with Instrument Serif for one word. Cloudflare Pages builds and hosts every push to the GitHub repository. There is no server: the music line reads Last.fm from your browser and keeps the last value it has when Last.fm cannot be reached. Every page ships at most 5 KB of gzipped JavaScript, which a local gate checks.

The design system is Ledger: text first, 1px lines and whitespace instead of cards, and green only for live state. [How it was built](/projects/this-site/) · [source](https://github.com/vedaant-rajoo/vedaant.dev)
